# Source fidelity (content only)

The pictures are invented, but what they say is not. Apply this while
planning and again when you score source fidelity in your self-review.

## Visual plans

- SOURCE FIDELITY: every source_asset_ids reference is a real, cited asset
  drawn from that shot's own scene. Each picture shows only what the scene's
  narration and cited content support: the people, events, objects, and
  outcomes the story actually describes, or a neutral everyday setting that
  illustrates the beat without adding a claim.
- Never picture a fact, result, or event the sources do not state -- a
  picture that implies something new is an invented claim.
- Never draw a recognisable likeness of a real person. When the sources name
  a real person, show a generic figure, a figure from behind, or a symbolic
  object instead.
- SOURCE UNCERTAINTY: check each cited asset's own "uncertainties"; if a
  picture would present an uncertain detail as fact, make that detail
  generic or leave it out.
